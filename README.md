# AFO — Automated File Organizer

파일 정리가 귀찮거나 저장공간이 부족한 사용자를 위한 자동 파일 관리 프로그램입니다.
교내 AI-SW 개발 해커톤 출품을 목표로 공동 개발합니다.

## 핵심 기능

1. **자동 분류·저장**: 흩어진 파일을 종류와 용도에 맞게 분류하고 알맞은 폴더로 정리합니다.
2. **확인 후 삭제**: 중복 파일 등 삭제 후보와 이유를 보여 주고, 사용자가 승인한 항목만 실제로 삭제합니다.

## 개발 방식

하네스 엔지니어링을 활용해 AI의 기획·개발·테스트 역할과 작업 규칙을 구성할 계획입니다.
파일 보존, 이름 충돌 방지, 승인 범위 준수, 이동 결과 확인을 검증 항목으로 삼습니다.

## 현재 상태

- 프로젝트 기획 및 저장소 초기화 단계입니다.
- 실행 가능한 프로그램과 개발 하네스는 아직 구현하지 않았습니다.
- 기술 스택, 대상 운영체제, 배포 방식과 역할 분담은 공동개발자와 정합니다.
- 대회 제출 URL에서 실제 동작을 확인할 수 있도록 제공 방식을 결정해야 합니다.

## 공동 개발

- 작업별 브랜치를 만들고 Pull Request로 변경 내용을 공유합니다.
- 구현 내용과 확인한 테스트 범위를 PR에 적습니다.
- 초기 파일 작업 검증에는 별도로 만든 테스트 폴더와 복사본을 사용합니다.
- 실제 사용자 파일, 개인정보, 비밀 키와 인증 정보를 저장소에 올리지 않습니다.
