# AFO 웹사이트 디자인 기준

목적: 파일이 쌓인 사람에게 AFO의 분류·개인 규칙·미리보기 흐름을 소개하고, 실제 파일 접근 없이 샘플로 체험하게 한다.

기준: 사용자가 지정한 https://www.joinswsh.com/ 실제 첫 화면과 섹션 구조를 2026-10-26 확인했다. 검정 배경, 중앙의 큰 흰 제목, 주황색 pill CTA, 외곽 비주얼, FAQ와 마지막 행동 유도 구성을 AFO에 적용한다. 이벤트 사진·고객 로고·투자 및 성과 수치는 옮기지 않는다.

## 제작 콘셉트

- `01-hero.png`: 1586×992, 헤더·히어로·정리 원칙. `02-demo.png`: 1435×1096, 체험과 3단계. `03-faq.png`: 1470×1070, FAQ·주황 띠·푸터.
- built-in Image Gen 사용. 히어로 콘셉트에서 웹 UI 문구만 제거한 별도 이미지 `public/assets/hero-art.png`를 생성했다. 모든 제목·메뉴·버튼·표·FAQ는 HTML이다.
- 토큰: 배경 #080808, 표면 #141414, 본문 #f7f7f5, 보조 #b0b0ad, 선 #333330, 주황 #f4512c. 외부 CDN 없이 Pretendard 1.3.9 자체 호스팅, OFL 라이선스 동봉.
- 글자: 히어로 약 90–104px/850, 섹션 64–88px/800, 본문 17–19px, 버튼 15–20px. 모바일 한글 실제 줄바꿈 별도 검수.
- 컨테이너: 히어로는 전면, 데모는 단일 목록 프레임, 사용 방법은 열린 번호 목록, FAQ는 수평 구분선. 반복 카드·가짜 성과 수치는 넣지 않는다.
- 아이콘: 1.7px 선의 화살표/더하기, 여섯 종류의 채운 문서 심벌. 파일 아이콘의 내부 기호는 일관된 어두운 선으로 그린다.

## 첫 화면 허용 문구

AFO / 기능 / 사용 방법 / 자주 묻는 질문 / 직접 체험하기 / 파일은 제자리에. / 당신은 다음 일에. / 어지러운 폴더를, 나다운 정리로. / 정리 흐름 체험하기 / 분류는 자동으로 / 규칙은 나답게 / 실행은 확인 후에.

모바일은 메뉴 버튼으로 세 메뉴를 접는다. 접근성 전용 건너뛰기 링크·aria-label은 보이는 카피 추가가 아니다. 이미지 안에 인쇄된 `보고서.pdf`와 `나의 프로젝트`는 비상호작용 장식이다.

## 의도적으로 보강한 동작

초기 상태는 콘셉트 표와 같다. 미리보기 이후 `문서 분류 기준` 선택과 `다시 체험하기`를 노출해 상태 변화가 실제로 보이게 한다. 이는 파일 엔진의 대체 구현이 아닌 고정 샘플의 미리 정의한 결과 전환이다. 샘플임을 화면과 FAQ에 명시한다. 3단계 설명은 브라우저 파일 선택 기능을 약속하지 않도록 로컬 CLI 기준으로 정정한다.

모바일은 외곽 이미지를 더 크게 잘라 중앙 제목을 보호하며, 목록은 파일명·크기와 목적지의 2줄 형식으로 전환한다. 데스크톱의 정보와 체험 동작은 보존한다.

## 이미지 생성 브리프

01: joinswsh의 검정/흰색/주황, 중앙 2줄 한글 제목, 외곽의 산 사진·주황 폴더·PDF·라임 폴더. 위 허용 카피와 넓은 중앙 여백을 지정.
02: 같은 디자인 시스템, 샘플 6개와 파일명·확장자·크기의 표, 미리보기 버튼, 3단계 번호 목록. 실제 파일 변경 없음 표시.
03: 같은 디자인 시스템, FAQ 세 개와 첫 답 펼침, 주황 띠와 마지막 체험 버튼, AFO 푸터.
배경 자산 편집: 01의 오브젝트·재질·위치는 유지하고 헤더·중앙 카피·CTA·하단 원칙만 제거, 물체 표면의 인쇄 문구는 보존.

## 2026-10-26 사용성 정리

사용자가 기존 분위기는 유지하되 산만한 구성을 정리하도록 요청했다. 최신 기준은 홈의 큰 브랜드 구도와 기능 화면의 작은 공통 위계를 구분하는 것이다. 메뉴를 직접 체험·나의 규칙·도움말로 정리하고 사용 방법/FAQ를 도움말에 모았다. 지원 화면 제목은 데스크톱 44px, 모바일 34px, 로그인은 38/32px의 중앙 단일 폼으로 정리했다. 과거 콘셉트의 반복 슬로건·큰 FAQ 제목·여러 군데의 체험 CTA를 지원 화면에 유지하는 것은 더 이상 목표가 아니다. JSON 기능은 삭제하지 않고 접힌 상세 도구로 묶었다. 실제 홈 자산·색·한글 서체는 유지한다.

## 2026-10-28 샘플과 실제 분석 구분

사용자 지적으로 별도 직접 체험 메뉴를 제거하고 주요 진입은 실제 폴더 분석(`/preview`)으로 연결한다. 고정 샘플은 도움말 안의 “샘플 분류 예시”로 옮기며, 가상 파일·미리 작성된 결과이고 실제 분석이나 개인 규칙은 실행하지 않는다고 명시한다. 기존 `/demo`는 `/help`로 이동한다. 기존 색·아이콘·표 스타일은 유지한다.
