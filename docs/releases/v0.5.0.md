문서 내용·사진 정보·개인 규칙을 함께 쓰는 선택형 분석과 이름 충돌 해결을 추가했습니다.

## 새 기능

- 이름 충돌: ‘둘 다 보관’용 안전한 새 이름 제안, 파일별 이름·목적지 수정, 이번 분석에서 건너뛰기.
- 복합 규칙 편집: 이름·확장자·상대 경로·크기·수정일 조건의 AND/OR, 우선순위, 테스트·켜기·끄기·삭제. 기존 규칙과 사용자 수정 보존.
- 문서 본문 분류: PDF, Office/HWPX/ODF/EPUB, 텍스트·RTF 등을 읽고 발췌와 근거 표시. 선택한 로컬 Ollama 모델 연동.
- 사진 촬영일: 저장된 EXIF 원본 촬영 날짜로 연도·월별 정리안 제안.
- 유사 사진: 픽셀 해시로 찾은 후보를 나란히 비교. 정확한 중복 삭제 목록에 자동 연결하지 않음.
- 확장자 분류표 확대와 `afo formats`, `afo formats --categories` 추가.

모든 파일 이동·삭제는 기존 미리보기·계획·승인·실행 직전 재검사 경로를 사용합니다. 사용자 자료로 자동 테스트하지 않습니다.

```sh
afo update
afo gui
afo preview "/작업/폴더" --conflicts keep-both --content --photo-dates month --similar-photos
afo formats
```

본문·OCR·사진 분석은 선택할 때만 추가 처리합니다. 로컬 AI는 설치된 Ollama 모델을 사용하며 모델을 자동 다운로드하지 않습니다. 구형 바이너리 HWP·DOC·XLS·PPT 등은 종류별 분류만 제공하며 본문 추출은 지원하지 않습니다. 이미지 해독·OCR은 OS 코덱과 OCR 언어 지원에 따라 달라지며 처리 한도·실패 이유를 표시합니다.

지원 범위·조건·한도·명령은 [문서·사진·복합 규칙 정리](https://github.com/fakeminjun7321/AFO/blob/v0.5.0/docs/SMART_ORGANIZE.md)를 확인하세요. macOS 배포 서명·공증, Windows 배포 서명은 제공하지 않습니다. VM/CI 결과는 Windows·Intel Mac 실물 검증을 대신하지 않습니다.
