# Firebase 연동 작업 범위

이 디렉터리는 #25의 Codex 전담 범위입니다. 루트 공용 계약·파일 실행기·CLI·package.json·lockfile·CI는 다른 작업자가 담당하므로 수정하지 않습니다.
Firebase의 실제 로그인·저장·배포는 별도 단계이며 현재 프로젝트가 없어 `demo-afo` Emulator로 검증합니다.
서비스 계정·관리자 SDK를 배포 클라이언트에 넣지 않습니다. 파일 내용·참고 파일명·절대 경로·로컬 실행 승인 자료를 업로드하지 않습니다.
클라우드 규칙 데이터는 로컬 파일 삭제 권한이 아닙니다. CLI·GUI 통합은 공용 계약 확정 후 별도 검증합니다.
