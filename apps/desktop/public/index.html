1. 작업 폴더 선택

정리를 제안받을 폴더입니다. 홈 전체·디스크 루트·시스템 폴더·개발 프로젝트는 선택할 수 없습니다.

선택한 작업 폴더가 없습니다.

2. 참고 폴더 선택 (건너뛸 수 있음)

이미 정리해 둔 폴더의 구조·이름·확장자만 읽어 규칙 후보를 만듭니다. 참고 폴더의 파일은 열거나 바꾸지 않습니다.

참고 폴더 없음(건너뜀).

3. 분석

작업 폴더를 선택하면 분석할 수 있습니다.

              5. 참고 규칙 후보

              참고 폴더에서 찾은 후보입니다. 체크한 규칙만 확인하며, 확인 전에는 적용하지 않습니다. 규칙 저장은 후속 작업입니다(이번 실행에서만 사용).

              적용할 규칙 선택

                실행 기능은 아직 연결하지 않았습니다. 파일 이동·삭제는 이 화면에서 할 수 없습니다.
