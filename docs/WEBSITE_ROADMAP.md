## 경계

웹 규칙 JSON은 휴대 가능한 규칙 계약이며 CLI의 참고 근거·루트 권한을 담은 로컬 프로필과 다르다. CLI 자동 적용·파일 변경 승인을 뜻하지 않는다. 샘플 체험은 기존 고정 샘플이며 규칙 화면의 사용자 규칙으로 실제 파일을 분류했다고 표시하지 않는다.

구현·단위 검증·Emulator·실제 클라우드·실물 기기를 각각 보고한다. 마우스/키보드/기존 탭을 조작하지 않고 별도 headless Chromium에서 테스트한다. Browser plugin/skill이 제공되지 않아 프로젝트 Playwright를 사용한다.
